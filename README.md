# Hi, I'm Valmir Formigari 👋

**Full-Stack Developer** · Information Systems graduate · MBA in progress

I build ERP systems and web applications, working mostly with **PHP**, **Node.js** and **TypeScript** on top of **MySQL** and **PostgreSQL**. I'm moving my career toward **Software Architecture**: designing systems that are easier to maintain, scale and evolve, especially when they start from legacy code.

Outside work I keep personal projects running, like a print queue manager for LAN printers and a service request app for maintenance technicians. New ones land here as they take shape.
